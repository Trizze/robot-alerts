Canvas resolution

This is a public, read-only display URL. It contains no credentials and cannot change your channel settings.

STEP 3 OF 4

Add it to OBS.

  1. In Sources, click + → Browser.
  2. Name it Robot Alerts and paste the URL you copied.
  3. Set Width to 1920 and Height to 1080.
  4. Leave Local file off. Keep the transparent background, then click OK.
  5. Place this source above your gameplay or camera sources.

The source is transparent between alerts. Changing the resolution here won’t change OBS properties automatically.
